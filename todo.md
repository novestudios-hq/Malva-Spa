# GitHub Push Checklist

- [x] Confirm the target repository and the local project state.
- [x] Commit the completed Malva Spa website and push it to `novestudios-hq/Malva-Spa`.
- [x] Verify the remote commit and report the result.
- [x] Prepare a portable static bundle and copy the generated visual assets for GitHub Pages.
- [x] Push the GitHub Pages-ready bundle and verify the remote commit.
- [x] Confirm the GitHub Pages deployment status and public site URL.
- [ ] Inspect the live public page, correct any issue, and confirm the fix.
- [ ] Switch GitHub Pages from the repository root to the `/docs` bundle and confirm publication.
- [ ] Publish the static bundle at the repository root to match the current GitHub Pages source.
